# For You

A private, personal website — a small gift, not a project for anyone else.

## What's inside
- A counter for time spent together
- Photos, video clips, and a few sealed letters
- Little things I've noticed, in card form
- A memory match game and a date-night idea spinner
- A promise, sealed for later
